# 1. Two Sum · Python

[原题](https://leetcode.com/problems/two-sum/)要求返回两个不同下标，其元素和等于target；原题保证唯一答案。实现保持LeetCode的`Solution.twoSum`接口，不修改输入。

从左向右扫描时，字典只记录当前位置之前的值与下标。处理value时查找target−value：若存在，两个位置已组成答案；若不存在，再登记当前位置。先查后存使`[3,3], target=6`能返回两个不同位置，也不会在仅有一个3时复用自身。重复值覆盖旧下标仍保留一个合法的此前位置。

例如`[3,2,4], target=6`：看到3先登记；看到2缺少4，登记2；看到4时查到此前2的下标1，返回`[1,2]`。哈希表操作按平均常数时间计算，预期时间O(n)、额外空间O(n)。Python整数无固定32位溢出；这里不把哈希表最坏情况写成确定的线性界。

无解输入不属于原题承诺，辅助本地使用时抛ValueError。测试覆盖普通、重复、负数、零、无解和输入不变；实际执行结果见PR。不声称已在线提交LeetCode。A实现，OpenAI Codex辅助整理。
