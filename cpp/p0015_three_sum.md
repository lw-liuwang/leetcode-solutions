# 15. 3Sum · C++17

[原题](https://leetcode.com/problems/3sum/)要求输出和为零的不同值三元组，每组必须来自三个不同下标。`vector<vector<int>> Solution::threeSum(vector<int>& nums)`先复制输入再排序，保留原数组；输出组内和组间顺序不作接口承诺。官方长度3..3000、值在正负100000内；不足三个元素扩展为空结果。求和先转long long，也支持int极值探测而不发生有符号溢出。

依次固定排序后首下标first，跳过与前一个相同的首值。剩余区间用left=first+1、right=n-1扫描。和小于0时增加left，大于0时减小right；等于0时记录当前三元组，跳过当前两端的所有重复值后继续。first<left<right始终保证三个位置不同；相同值可以合法出现在不同位置，例如三份零。

固定首项后，若当前和太小，保留left且把right移向更小值只会使和更小，因此这个left不可能组成目标；和太大时对称排除right。记录一组后，对于相同首值和左值，满足和为零的右值由方程唯一决定，所以重复左值不会产生新的值三元组；重复右值同理。跳过重复首值仍完整覆盖它所有可能的剩余两值。每组按排序位置产生，不同首值或两值组合不会重复，且每种合法组合都未被错误排除。

排序O(n log n)，每个首项的双指针O(n)，总时间O(n²)。为了保持输入，复制数组占O(n)额外空间；排序栈O(log n)包含在内。结果有k个三元组，输出占O(k)，不能把包含输出后的总空间写成常数。

独立oracle枚举i<j<k的全部下标三元组，宽类型求和后将值排序放入set形成期望。生产结果只排序归一化，绝不去重，这样错误重复输出仍会导致失败。五值长度3..7共97625个数组；6个固定例子包含重复零、重复值配对与int上下界扩展，3个短长度扩展。长度3000的全零数组应只输出一组三零，全正数组应无结果。每次核对原输入不变。

A补写排序输入[-2,-2,0,0,2,2]的去重账本，first/left/right为0基：

| first / left / right | 对应值与和 | 动作 |
| --- | --- | --- |
| 0 / 1 / 5 | -2,-2,2，和-2 | left变2 |
| 0 / 2 / 5 | -2,0,2，和0 | 记录[-2,0,2]；跳过两个0使left=4，再跳过右侧2使right=4，内循环终止 |
| first=1 | 首值-2与前值相同 | 跳过此first |
| 2 / 3 / 5 | 0,0,2，和2 | right变4 |
| 2 / 3 / 4 | 0,0,2，和2 | right变3，内循环终止 |
| first=3 | 首值0与前值相同 | 跳过，外循环随后终止 |

输出只有一组[-2,0,2]，重复输入值不等于应重复输出。找到解后左右跳过只跳相同值，不能跳过尚未比较的不同候选；三个下标始终不同，三零情况也合法。

对小值输入全体取负，任意三下标之和为零当且仅当原和为零；值三元组同时取负形成解集的双射，排序仅用于归一化输出。A对97625个长度3..7、值[-2,2]枚举各增加一次该映射检查，映射后仍在官方范围，使用原独立三下标oracle的期望逐元素取负。生产结果仍只排序而不去重，因此重复错误不会被set掩盖。INT_MIN/MAX扩展和大边界不取负，避免有符号溢出或扩大测试合同。A实际编写上述账本、证明与测试，未本机编译C++，最终运行需B补充。
