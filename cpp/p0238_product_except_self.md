# 238. Product of Array Except Self · C++17

[原题](https://leetcode.com/problems/product-of-array-except-self/)求每个位置以外的全部元素之积。`vector<int> Solution::productExceptSelf(vector<int>& nums)`不修改输入，不使用除法。合同为长度2..100000、值在-30..30，任意前缀/后缀的乘积及每个答案都在32位有符号范围内；不扩展到违背数值保证的输入。

第一趟从左到右，prefix初值1。在下标i先写result[i]=prefix，再乘入nums[i]；因此result[i]保存严格左侧元素之积。第二趟从右到左，suffix初值1。在当前位置先将已有左积乘suffix，再把当前值乘入suffix。若先更新suffix，答案会错误地包含当前位置自身。

第一趟迭代开始时prefix等于区间[0,i)之积；赋值后乘当前项，建立下一次不变量。第二趟处理j时suffix等于(j,n)之积，result[j]已有[0,j)之积，二者相乘恰好覆盖除j之外的所有下标且不重不漏。空前缀/空后缀的乘法单位元1正确处理首尾位置。循环以size_t的i>0为条件访问i-1，不计算无符号的-1下标。

零不需要特殊分支：一个零使其余位置的某侧乘积含零，零所在位置仍可组合两侧非零积；两个及以上零使每个排除结果仍含零。负号也由整数乘法自动处理。prefix和suffix始终是题目保证的前后缀乘积，最终乘入result的值是题目保证的答案；包括最后一次得到的整段乘积也受前后缀保证约束。因此在该合同下int运算有定义，不能仅凭输入单个元素小就忽略乘积范围。

两次线性遍历，时间O(n)。输出数组O(n)，除输出外只用prefix、suffix和循环下标，辅助空间O(1)。没有额外左右乘积数组。

独立oracle对每个排除下标直接遍历所有其他位置，用long long求积并检查int范围，不使用前后缀方法。五值集合上长度2..7共97650个数组全部落在数值合同内。4个固定例子覆盖零、双零、负数及两元素；边界包括31个-2（完整积为INT_MIN、每个排除积为1073741824），以及100000个1上分别零个、一个和两个零的情形。每次核对输入不变。

A补写nums=[−1,2,0,3]的完整两趟账本。第一趟每步先把旧prefix写入result，再乘当前值：

| i | nums[i] | 写入前prefix | 写入result[i] | 乘入后的prefix |
| --- | --- | --- | --- | --- |
| 0 | −1 | 1 | 1 | −1 |
| 1 | 2 | −1 | −1 | −2 |
| 2 | 0 | −2 | −2 | 0 |
| 3 | 3 | 0 | 0 | 0 |

第一趟结束result=[1,−1,−2,0]。第二趟从右往左，先乘严格右侧积再更新suffix：

| j=i−1 | 乘入前suffix | 原左积 | 最终result[j] | 乘当前值后的suffix |
| --- | --- | --- | --- | --- |
| 3 | 1 | 0 | 0 | 3 |
| 2 | 3 | −2 | −6 | 0 |
| 1 | 0 | −1 | 0 | 0 |
| 0 | 0 | 1 | 0 | 0 |

只有零所在位置得到−6，结果[0,0,−6,0]。若在j=2先把0乘入suffix，便会错误丢掉这个非零答案。

输入反序使原下标j对应n−1−j，排除该下标后相乘的元素仍相同，故输出也应反序。反序还交换前缀和后缀，保留原合同的32位乘积保证；它不引入新值或改变长度，31个−2和100000长度边界也合法。A对97650个小输入、4个固定例子和4个边界共97658次exact调用增加反序核对，并另拍快照检查变换后输入保持；原排除下标oracle保留，没有加入除法。
